O App-Tempo permite que o usuário informe uma cidade ou local e visualize informações climáticas em tempo real, como temperatura atual e condições do tempo.

O projeto foi desenvolvido com foco em praticar consumo de APIs e desenvolvimento front-end.

Funcionalidades:
Busca de clima por cidade
Exibição da temperatura atual
Informações básicas sobre o clima
Atualização dinâmica dos dados
Interface simples e intuitiva

Tecnologias utilizadas:
HTML
CSS
JavaScript
API de clima (Weather API)
